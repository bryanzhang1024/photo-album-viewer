# 「文件夹」页换法 · 准备轮记录（2026-10-27）

> 阶段：准备。本轮只做诊断与样张，不动产品代码。样张：[folder-page-round1.html](folder-page-round1.html)。

## 这一轮回答什么

这一页（侧栏「文件夹」→ `RootsPage`，标题写「照片来源」）换成什么才有用；三种换法的样子与代价摊开，你挑一个，下一轮才写计划。

## 现状为什么没劲

1. **和侧栏是同一份清单。** 这页只渲染来源列表（`src/ui/features/roots/RootsPage.jsx:14,83-115`），侧栏也渲染同一份（`src/ui/shell/Sidebar.jsx:126-160`）。点侧栏「文件夹」进来，看到的还是刚才点过的那九行，只是换成了大卡。
2. **卡面没有能用来判断的信息。** 副行只有「N 个文件夹 · 绝对路径」（`RootsPage.jsx:110`），没有图片数、没有修改时间。今天实扫：9 个位置里首层图片为 0 的有 6 个，光看文件夹数分不出哪边刚进了新套图。
3. **封面是随机第一张。** 取 `approximate.coverSamples[0]`（`RootsPage.jsx:85`）；容器型根取不到图就退成灰框加一个 15px 图标——你截图里两个 Collection 就是这个状态。而规格第 9 条本来要求文件夹卡用 2×2 拼贴（`design/shell-spec-final.md:17`），拼贴组件也早就有了（`src/ui/components/FolderCover.jsx:27-35`），这页没用。
4. **两个 Collection 分不出来。** 卡面只有 label，没有卷名；侧栏反而有「· 1TB」后缀（`Sidebar.jsx:34-39`）。
5. **一屏两个名字。** 侧栏和标签页写「文件夹」，页头写「照片来源」。

## 今天实扫到的实情（样张用的是这些）

- 9 个位置，**5 个嵌在别的位置里**：兴趣 ⊂ Collection·1TB；300/400/600 ⊂ Collection·1TB-2；twitter_media_harvest、P图用模特 ⊂ Downloads。同一批图会在两个入口各出现一次。
- 首层规模差三个数量级：300-Cos套图库 9,585 个文件夹、400 有 50、twitter_media_harvest 是 277 张散图。
- 近七天真的有事发生：兴趣/003-banana pro 今天 3,088 张，300-Cos套图库 10-26 进了 3 套 Machi，Downloads/2610_Kotone 10-26。
- 拿不到的：目录总大小、递归张数、磁盘剩余（快照只算一层，没有 statfs）。

## 三种换法

**A · 接着看 + 最近有变化（推荐）**
页面只干两件侧栏干不了的活：上方两张「上次打开的位置，点一下回到那一层」；下方跨来源按修改时间排的「最近有变化」列表（名称 / 来源 / 张数 / 时间，带 34px 缩略图）。来源注册表留给侧栏，不再重复。
代价低：快照本身就带每个子目录的 mtime 和 directMediaCount（`src/main/services/DirectorySnapshotService.js:335-343`），「最近有变化」等于把现在已经在做的首层扫描换个排序，不额外扫盘；「接着看」只需按来源存一个上次相对路径。

**B · 位置体检**
这页变成一张表：位置、文件夹数、首层图片、最近修改、标记（嵌在谁里面 / 只有散图 / 同名）、右侧「⋯」管理（改名、移除、Finder 打开、拖动排序）。上方三块计数说明问题规模。
代价低：嵌套判定是纯路径前缀，同名是 label 比较，表格用现成的 PageHeader / StatusBar。它解决的是「维护」而不是「进去看东西」。

**C · 不建页**
侧栏「文件夹」直接回到上次打开的位置；来源管理收进设置或侧栏右键。改动最小，但等于承认这页没有独立价值。

## 要你定

1. 三选一（或组合，例如 A 里嵌一条 B 的「问题提示」）。
2. 页面名字：A 叫「文件夹」，B 留「照片来源」。
3. 如果选 A：Cos 总览的「最近添加」和这里的「最近有变化」怎么分工——现在 Cos 总览只看 cos 根，A 跨全部来源。

## 实现的已知边界

- 目录总大小、递归张数、磁盘剩余都没有现成能力，要做得加主进程 IPC；本轮三个方案都不依赖它们。
- 这页现在对 9 个根并发做首层扫描，300-Cos套图库这种要 9,585 次 readdir + stat（`DirectorySnapshotService.js:285-292`）。A 沿用它但只排序不新增扫描；若要更快，得另做「只取最近 N 个」的裁剪，属于计划阶段的事。
- 2×2 拼贴、缩略图、面包屑跳转都能直接复用，不需要新组件。
