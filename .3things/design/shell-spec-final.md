# 设计定稿（2026-10-24）

> 本文件只管界面规格；项目当前状态见 [../project.md](../project.md) 顶部。

状态：用户已全部确认。实现前不再改动设计；实现中发现必须调整的，回到这里改并记一条原因。

## 一、已确认的决定

1. 卡片：主行完整名去掉当前署名前缀与末尾作品括号，次行作品与张数（丙）。
2. 整体：暗色 macOS 原生观感。分层底色、细线分隔、无阴影；侧栏 + 面包屑 + 前进后退 + 标签页。
3. 结构：文件夹与 Cos 图库合并成一个框架，用侧栏切换，不再分两个模式。
4. 打开方式：单击选中、双击打开、空格快速查看。（2026-10-25 修订：网格改为单击打开；列表保持 Finder 习惯——单击选中、双击打开、回车打开。空格快速查看仍不在 4.0。）
5. 设置：独立窗口，⌘, 打开，固定 760×560。
6. Cos 图库保留总览页，放根目录管理与最近添加。
7. 侧栏默认展开，窗口窄于 960 自动收起，可用工具栏按钮临时展开。
8. 混合目录：卡片给「子文件夹 N」角标，点角标进子目录，双击进图片。
9. 文件夹卡封面用 2×2 拼贴；Cos 套图卡用单张 3:4。
10. 列表：文件夹层 名称 / 图片 / 子文件夹 / 修改日期；照片层 名称 / 大小 / 修改日期。去掉「种类」列。
11. 列表可排序，点列头切换升降序；排序偏好全局记住，文件夹始终在前。
12. 文件夹的「大小」只算直接图片，不递归。
13. 文件夹模式补 HEIC / AVIF 识别；非图片文件不进网格，状态栏提示数量。
14. 面包屑超过四段时中间截断。
15. Esc 分层（2026-10-27 修订）：Esc 每次只退一层，按页面层级——浮层 → 信息面板 → 查看器（全屏先退全屏）→ 搜索框（有搜索词时清空并退出输入框）→ 上一层页面。选中态和页面级搜索词不单独占一层；照片来源、我的收藏、Cos 总览、设置窗口是顶层，无动作；`⌘↑` 与 Esc 退同一层。修订原因：原句没写选中/搜索算不算一层，4.2 快捷键收口时另加了「Esc 取消选中」，Cos 列表页又漏接退层，同一个 Esc 实际出现七种结果（统计与决定见 [plan-esc-layers.md](../plan-esc-layers.md)）。
16. 快捷键：⌘[ 后退、⌘] 前进、⌘↑ 上一级、⌘F 搜索。
17. 响应规则：≥1440 侧栏 240、7–9 列；1100–1439 侧栏 216、5–6 列；900–1099 收起侧栏、5 列；700–899 4 列；最小 720×480、3 列。
18. 头部：网格用方案一（标题与控件同行），列表与窄窗口用方案二（单行头部，排序用列头），顶部占用从 194px 降到 118px。
19. 查看器信息面板固定 300px，窗口窄于 960 改覆盖层。

## 二、开工顺序

1. **壳层**：主题 token、侧栏、工具栏（前进后退）、面包屑、标签页、暗色配色。
2. **列表视图**：列头排序、拼贴封面、混合目录角标、响应规则。
3. **查看器**：换样式，补双页、信息面板响应式。
4. **其余页面**：Cos 各页、收藏、搜索、设置窗口、空状态与错误状态。

每一步的验收：既有测试通过、`npm run build` 通过、安装到 `/Applications` 并在真实图库上跑一遍；用户可见改动同步版本号与 CHANGELOG。

## 三、开工前的已知风险

- 现在是单文件大页面结构（BrowserPage 1411 行、CosLibraryPage 1015 行），壳层改造会先碰到这两处，需要边拆边保证行为不变。
- 双击打开会改变现有单击直达的习惯，需要同时更新测试与文档。
- 暗色主题是全局替换，浅色主题要跟着改，否则会退化成两套。
- 9,591 个文件夹的拼贴封面需要采样 4 张图，首屏开销比单图大；实现时按可见区域懒加载。
