## 二、已经定下来的

1. 卡片用丙：主行完整名去掉当前署名和末尾作品括号，次行作品与张数。
2. 整体走暗色 macOS 原生观感：分层底色、细线分隔、无阴影；侧栏 + 面包屑 + 前进后退 + 标签页。
3. 文件夹与 Cos 图库合并成一个框架，侧栏切换，不再是两个模式。
4. 列表可排序：名称、图片、子文件夹、修改日期；照片层用名称、大小、修改日期。

## 三、需要你确认（6 条，括号里是我的建议）

1. 打开方式：单击选中、双击打开，空格快速查看（建议按 Finder），还是保留现在的单击直接进。
2. 设置放在哪：独立窗口 + ⌘, 打开（建议），还是留在主窗口里当一页。
3. Cos 图库要不要「总览」页（建议保留，放根目录管理和最近添加）。
4. 侧栏默认展开还是收起（建议展开；窗口窄于 960 时自动收起）。
5. 工具栏是否减负：把排序和密度合成一个「显示」按钮（建议合并，现在一排六组控件偏挤）。
6. 混合目录怎么进：卡片上给「子文件夹 N」角标，点角标进子目录、双击进图片（建议这样），还是两个按钮平铺。

## 四、我按建议直接定，你事后可以改

1. 文件夹卡封面用 2×2 拼贴，Cos 套图卡用单张 3:4。
2. 列表去掉「种类」列；文件夹层是名称/图片/子文件夹/修改日期，照片层是名称/大小/修改日期。
3. 文件夹的「大小」只算直接图片，不递归。
4. 文件夹模式补 HEIC/AVIF 识别（解码能力已有）。
5. 非图片文件不显示在网格，状态栏提示「另有 N 个视频/压缩包」。
6. 面包屑超过四段时中间截断。
7. 排序偏好全局记住，不按目录记；文件夹始终排前面。
8. Esc 分层：先关浮层，再关查看器，最后退一级。
