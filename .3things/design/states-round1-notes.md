# 补充样张 · 状态与设置（2026-10-25）

用途：补 12 屏主样张没画的界面，避免 4.0 实现时在这些地方自行发挥。与主样张同一套 CSS。

材料：`states-round1.html`（5 屏，点左侧切换）、`screens/state-50`~`state-54` 截图。

## 五屏

1. **state-50 搜索无结果**：搜索范围是当前文件夹（4.0 不扩到跨来源）；空状态沿用第 11 屏的空状态样式；动作只保留「清空搜索」，不放没实现的入口。
2. **state-51 Cos 首次建立索引**：整页状态，转圈 + 进度条 + 套数/已用时/约剩；说明建好后会缓存；建立期间不提供部分浏览，与现有行为一致；状态栏写明不会修改源图库。
3. **state-52 Cos 后台刷新**：顶部细条提示「正在后台核对更新，现在显示的是 10 分钟前建立的索引」，内容照常浏览，右侧「查看进度」。
4. **state-53 离线与解码失败**：两张窗口。
   - Cos 套图列表里，来源盘离线的套图用遮罩「源盘不可用 + 挂载点名」，卡片文字照常显示。
   - 相册里解码失败的照片用「无法显示 + 文件已损坏或格式不支持」占位，0 字节。
   - 相册页头右侧排「上一套/下一套 + 收藏 + 设置 + 排序 + 密度」，补上主样张没给相邻导航留的位置。
5. **state-54 设置四标签**：2×2 展示四个标签的内容。
   - 通用：主题、默认视图、显示文件名、默认双页、自动旋转竖图、恢复上次标签页。
   - 浏览：排序方式、封面模式、支持格式说明。
   - 缓存：缩略图缓存、相册与导航缓存、清理缓存、刷新统计。
   - 图库：索引状态、刷新索引、根目录在线/离线；增删根目录仍在 Cos 图库总览页，设置只显示状态。

## 实现时沿用的规则

- 状态条、空状态、遮罩三套样式都复用主样张已有的 `.banner`、`.empty-box`、`.mask` 写法，不新造组件。
- 遮罩文案固定：离线 =「源盘不可用 + 挂载点名」；解码失败 =「无法显示 + 文件已损坏或格式不支持」。
- 状态栏负责汇总数量（几套离线、几张无法显示），卡片上不再重复长句。
