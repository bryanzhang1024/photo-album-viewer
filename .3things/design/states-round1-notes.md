# 补充样张 · 状态与设置（2026-10-25）

用途：补 12 屏主样张没画的界面，避免 4.0 实现时在这些地方自行发挥。与主样张同一套 CSS。

材料：`states-round1.html`（5 屏，点左侧切换）、`screens/state-50`~`state-54` 截图。

## 五屏

1. **state-50 搜索无结果**：搜索范围是当前文件夹（4.0 不扩到跨来源）；空状态沿用第 11 屏的空状态样式；动作只保留「清空搜索」，不放没实现的入口。
2. **state-51 Cos 首次建立索引**：整页状态，转圈 + 进度条 + 套数/已用时/约剩；说明建好后会缓存；建立期间不提供部分浏览，与现有行为一致；状态栏写明不会修改源图库。
3. **state-52 Cos 后台刷新**：顶部细条提示「正在后台核对更新，现在显示的是 10 分钟前建立的索引」，内容照常浏览，右侧「查看进度」。
4. **state-53 离线与解码失败**：两张窗口。
   - Cos 套图列表里，来源盘离线的套图用遮罩「源盘不可用 + 挂载点名」，卡片文字照常显示。
   - 相册里解码失败的照片用「无法显示 + 文件已损坏或格式不支持」占位，0 字节。
   - 相册页头右侧排「上一套/下一套 + 收藏 + 设置 + 排序 + 密度」，补上主样张没给相邻导航留的位置。
5. **state-54 设置四标签**：2×2 展示四个标签的内容。
   - 通用：主题、默认视图、显示文件名、默认双页、自动旋转竖图、恢复上次标签页。
   - 浏览：排序方式、封面模式、支持格式说明。
   - 缓存：缩略图缓存、相册与导航缓存、清理缓存、刷新统计。
   - 图库：索引状态、刷新索引、根目录在线/离线；增删根目录仍在 Cos 图库总览页，设置只显示状态。

## 实现时沿用的规则

- 状态条、空状态、遮罩三套样式都复用主样张已有的 `.banner`、`.empty-box`、`.mask` 写法，不新造组件。
- 遮罩文案固定：离线 =「源盘不可用 + 挂载点名」；解码失败 =「无法显示 + 文件已损坏或格式不支持」。
- 状态栏负责汇总数量（几套离线、几张无法显示），卡片上不再重复长句。

## 第二批（同一轮补的 6 屏）

- **state-55/56/57 收藏**：两段改为「文件夹 / 图片」；套图卡与普通文件夹卡混排；失效收藏显示「找不到这个文件夹」；两段都空时的引导。
- **state-58 查看器双页**：两页并排，底部双页开关高亮。
- **state-59 相簿单选**：替换第 4 屏的多选版本；状态栏只写已实现快捷键。
- **state-60 搜索结果**：当前文件夹范围，顶部写明范围。

完整合并版见 `design-book.html`（37 屏、十六节、内嵌实时 HTML），之后以它为准，本文只作规则说明。

- 列表 **单击选中、双击打开、回车打开**，按 Finder 习惯。

## 第五批（头部落位）

- 所有主屏替换成已确认的头部：**网格用方案一**（标题与控件同行，不显示面包屑），**列表与窄窗用方案二**（面包屑、标题、数量、控件压成一行）。
- 原来主屏仍是三行头部（面包屑 + 大标题 + 控件行），第 3 屏列表仍写着「张数 / 种类」；现在全部改掉，列表四列是名称 / 图片 / 子文件夹 / 修改日期。

## 第四批（2026-10-25 评审后修正）

- 新增 **s14 文件夹 · 列表（修正）**：替换旧第 3 屏。旧样张是「张数 / 种类」两列，与定稿的四列不一致；新屏为名称 / 图片 / 子文件夹 / 修改日期，单行头部，排序用列头。
- 所有样张支持 `?embed=1#sN` 深链，设计稿用它内嵌实时界面（37 屏一起加载），不再用截图评审。已用 Chromium 内核实测渲染正常。
- 旧设置屏（第 12 屏）不再进入设计稿，设置统一由 state-54 的四标签表达。

## 第三批（按四个真实目录的决策补的 2 屏）

- **state-61 只有视频的文件夹**：网格显示「这个文件夹里没有图片 / 有 14 个视频」，并给「用列表查看」；列表按名称 / 类型 / 大小 / 修改日期列出视频，双击用系统播放器打开。对应 `Collection/下载/交锋`（11 个 mp4 + 3 个 mkv）。
- **state-62 裁切 / 完整显示**：同一批图片两张窗口对比。默认裁切（长截图只看到中间一段）；页头开关打开后按原比例完整显示（长截图、参考图完整可见），开关状态按文件夹记住。
- 设置「浏览」标签新增一行「每个文件夹分别记住视图与排序」，默认开启。
