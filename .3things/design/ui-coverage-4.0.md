## 判定口径

- **现状**：3.13.1 有没有这个能力。
- **样张**：`.3things/design/` 有没有画。
- **分类**：外观 / 结构·操作 / 功能·能力 / 状态。
- **4.0 处理**：照做（重写界面） / 保留换样式（能力不变） / 4.0 不做（不留假入口） / 待补规格。
- 总原则：4.0 = 外观 + 样张已画的结构与操作；**功能能力一项不加、一项不删**。

## 需要用户拍板

1. **多选与空格快速查看**：样张画了但软件没有。建议 4.0 不做，界面不出现勾选态、状态栏不写空格快捷；等以后做这两个功能时再加。
2. **跨来源搜索**：第 10 屏画的是「全局搜索」，软件目前只有当前层与 Cos 索引搜索。建议 4.0 不扩搜索范围，按现有能力重画这张样张，保证样张与实现一致。
3. **设置四标签**：样张是四个标签，软件是单页滚动。建议照样张做四个标签，把现有设置项归类；没有内容的标签写「暂无设置项」。

其余各项按表中处理执行，不需要逐条确认。
