# 暗色 Mac 风格 · 第一轮样张

状态：等待用户选择方向。本轮只产出静态样张，未改应用代码、未建功能分支、未升版本、未构建安装。

## 本轮只判断什么

现在这版界面是 Material Design（MUI）的观感，用户希望试 macOS 原生观感，并且要暗色。判断的是：侧栏常驻 + 面包屑 + 前进后退 + 图标/列表两种视图这套骨架，在暗色下是否成立、是否比现在舒服。

同时验证三条新反馈能不能放进同一个框架：

- 同一个目录可以切缩略图网格和文件列表两种看法，用来挑要进哪个文件夹；
- 有前进/后退按钮，配合 ⌘[ / ⌘] 与 ⌘↑ 到上级；
- 左侧侧栏可展开收起，标签页继续保留。

## 三个屏幕

1. 网格视图：侧栏常驻；工具栏左侧放侧栏开关和前进/后退；主区顶部是面包屑、标题、分类分段控件、排序与密度；卡片显示套图名（去掉署名前缀）、作品和张数。
2. 列表视图：名称、张数、角色、作品、修改日期五列，保留 22×29 缩略图。用于"认不出是哪套"时按文字读信息。
3. 侧栏收起：内容区变宽，同尺寸卡片一屏多放一列；工具栏侧栏按钮保持高亮。

## 材料与边界

- 数据来自本机真实 Cos 图库索引（`userData/cos-library-catalog-v1.json`）：300 库共 9591 套，取署名"半半子"的 120 套里 12 套。
- 封面从原图缩放后内嵌进 HTML，页面可离线双击打开；源图库未修改。
- 配色与尺寸是样张选择，不是最终设计 token；侧栏材质、圆角、字号需要在实现阶段对齐系统控件。
- 布局参照 macOS 平台的通行结构，未复制 Apple 品牌素材或第三方字体。

## 验证

- Electron 离屏渲染三屏，视口 1356 × 1000（窗口 1280 × 800），三屏均无横向溢出，封面图全部解码成功。
- HTML 单文件自包含，体积 657 KB，双击可直接打开，切换按钮可用。
