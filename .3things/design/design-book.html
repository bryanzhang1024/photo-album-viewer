Photo Album Viewer · 4.0 界面设计稿

主样张、补充样张、散乱目录、响应式、头部五组合并，补上缺失状态、修掉互相矛盾的地方。每张卡片都是内嵌的实时界面，不是截图。

怎么用：点任意一屏放大查看，可滚动、可缩放，字体和控件都是真实渲染；「在新窗口打开」可单独开一页。实现时颜色、字号、间距以 HTML 原件为准，验收就是同尺寸并排比对。

一、对象分类：两个对象，三种卡片

原来的说法是「文件夹 / 相簿（即套图）/ 单张图片」三类。核下来这三个词指的是同一个东西，差别只有两点：有没有子文件夹、有没有 cosset 元数据。

问题

  • 同一个磁盘目录，在文件夹页叫「文件夹」，打开后叫「相簿」，在 Cos 图库里叫「套图」，收藏页又把文件夹和相簿合并在一个标签里。
  • 要按「类别」分叉的地方因此变多：收藏、搜索、卡片文字、排序各要写一套规则。
  • 用户要先知道自己站在哪个模式里，才能判断眼前这张卡片点进去会发生什么。

建议

  • 两个对象：文件夹、图片。
  • 文件夹的卡片按内容变形态，而不是分三种类别。
  • 「相簿」从界面词表里去掉；页面标题就是文件夹名，数量写「N 张照片」。
  • 「套图」只保留在 Cos 图库语境里（按署名 / 按角色 / 全部作品），因为那里对象确实都带元数据。
  • 底层数据和收藏记录都不变，变的只是名字和卡片形态。

文件夹卡

有子文件夹的目录。显示「子文件夹 N · 图片 M」，双击进入。

图集卡 / 套图卡

只有图片的目录。显示「图片 M 张」；带 cosset 元数据时加作品与署名上下文，就是「套图」。

图片

单张照片。双击打开查看器，心形加收藏。

场景现在的说法4.0 的说法
侧栏导航文件夹 / 我的收藏 / Cos 图库不变
进入 300 库里的套图相簿（也有人说套图）打开一个文件夹，照片数量写「N 张照片」
进入普通目录文件夹不变
收藏页相簿 / 图片文件夹 / 图片
搜索分组套图 / 文件夹文件夹 / 图片
Cos 图库套图套图（保留，仅这一处）

这条改动最大的是词表：界面里不再出现「相簿」。如果你更习惯「相簿」这个词，也可以只在照片网格页保留它，其余地方用「文件夹」。

二、窗口外壳与导航

所有页面共用同一套外壳：工具栏（侧栏开关、前进后退、居中标题）、标签栏、侧栏、页头、状态栏。下面都是可交互的实时界面，不是截图。

三、相簿与查看器

一个文件夹里只有图片时，双击就进照片网格；页头右侧放相邻换套与收藏、设置、排序、密度。

四、Cos 图库

文件夹的一个索引视图：按角色、按署名、全部作品，底层仍是同一批目录和图片。

五、收藏

两段：文件夹、图片。套图是带 Cos 元数据的文件夹，和普通文件夹在同一个段里混排，按收藏时间排。

六、搜索

搜索范围是当前文件夹（不扩到跨来源）；结果和收藏一样按「文件夹 / 图片」分组。

七、设置

独立的 760×560 窗口，四个标签；下面四张是同一窗口的四个标签。

八、状态与异常

空、离线、解码失败这几种状态在主样张之外单独定样式。

九、散乱目录与列表变体

真实图库里不只有一层套图文件夹：按月份、按作者、平铺、以及只有视频的下载目录。

十、响应式

侧栏宽度、网格列数、控件收敛按窗口宽度分档；最小窗口 720×480。下面是可拖动的实时界面。

十一、头部与密度

两种头部：网格用方案一（标题与控件同行），列表与窄窗口用方案二（单行头部，排序用列头）。

十三、这次改了什么

  • 分类收敛：从「文件夹 / 相簿 / 套图 / 图片」收敛到「文件夹 / 图片」，套图变成卡片形态。
  • 收藏补齐：两段结构、普通文件夹卡、失效收藏、空状态、列表视图。
  • 相簿改成单选：去掉 4.0 不做的多选与批量快捷键。
  • 搜索按现有范围：结果页与无结果页重画，替换原来的全局搜索样张。
  • 补双页查看：查看器原来没画双页。
  • 补状态与设置内容：索引建立、后台刷新、离线、解码失败、设置四标签。
  • 快捷键统一：状态栏只写已经实现的快捷键，不再出现假入口。
  • 非图片文件能在列表里看到（用户确认）：类型 / 大小 / 时间三列，网格里给「没有图片」的说明和「用列表查看」。
  • 完整显示开关（用户确认）：默认裁切，开关打开后按原比例显示，按文件夹记住。
  • 每个文件夹分别记住视图与排序（用户确认）：下载这类目录可以固定用列表 + 按修改时间倒序。
  • 样张合并成一份：37 屏按用途分十六节，这份就是实现和验收的唯一对照。
  • 设计稿改为可交互：每个屏幕都是内嵌的实时 HTML，点开可放大、可滚动，不再用截图评审。

十四、需要你确认的

  1. 「相簿」退出词表，统一叫文件夹，可以吗？（这是这次改动最大的一条）
  2. 收藏页支持列表视图：我按「支持」画的；如果你更想保持只有网格，这一项要去掉。
  3. 相册页头右侧放「上一套 / 下一套 + 收藏 + 设置 + 排序 + 密度」，比主样张多了一组相邻换套按钮。
  4. 设置「图库」标签只显示状态，增删根目录仍回 Cos 总览页。
  5. 状态栏快捷键目前只列 ⌘[ ⌘] ⌘↑ ⌘F 与「双击打开」，要不要再加 ⌘,（设置）和 ⌘W（关标签）。

十五、明确不做（4.0 范围外）

4.0 只换界面与交互形态，下面这些是功能能力，界面上不出现入口，等以后单独排期。

  • 多选与批量操作：⌘A 全选、⌘O 打开、⌘⌫ 批量移到废纸篓。相簿只做单选。
  • 空格快速查看：状态栏不出现这条提示。
  • 跨来源全库搜索：搜索范围只到当前文件夹，Cos 图库单独搜。
  • 大平铺目录的按日期分组 / 快速定位：3,055 张的目录仍靠滚动和搜索。
  • Quick Look 预览：与空格快速查看同一条，不做。
  • 多窗口行为改动：沿用现有打开方式，不重画。
  • 标签拖拽排序：沿用现有行为，不新增拖拽交互。
  • 浅色主题逐屏对齐：保留浅色可用，但只按暗色样张验收。
  • 主进程能力改动：目录扫描、索引算法、缩略图管线都不动，只换界面层。
