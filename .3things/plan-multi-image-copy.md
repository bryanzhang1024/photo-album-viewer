## 已确认交互与本计划的具体口径

- 在网格空白处按下左键拖出选择框，与图片卡片相交即选中；有实际拖动才框选，松手不误开大图。首版框选当前可视区域，不做拖框触边自动滚屏；选中后可正常滚动并用 ⌘点选追加。
- ⌘点图片切换该图是否选中；Shift 点图片，按当前显示顺序选择从最近选择锚点到该图的一段，无锚点时只选当前图。修饰键选图不打开大图。
- 普通点击图片继续打开大图；普通点击网格空白取消选择。选中显示蓝色描边及底色，复用卡片选中样式，不另加选择模式开关或批量工具栏。
- 鼠标多选保存在图片身份集合中，不靠 DOM 节点存储；滚出虚拟网格后仍保留选择。换标签、换目录/套图、换搜索或排序时清掉本轮多选，避免复制已不在当前结果中的图；原有键盘导航仍按既有口径工作。
- ⌘C 按当前网格显示顺序复制所有选中的原始文件，去除重复路径；不按点选先后排序。没有多选时不清空系统剪贴板，也不拦截正常文本复制。
- 查看器打开时 ⌘C 仍复制正在看的单张，⌘⇧C 仍复制该图像素；已有 Esc 页面退层规则不新增“取消多选”一层。

## 推荐实现

最小方案：复用当前 macOS 原始文件复制逻辑，把单路径 plist 扩展为有序路径数组；不升级 Electron，不增加原生模块、安装依赖、配置开关、凭据或常驻服务。

保留 `COPY_IMAGE_TO_CLIPBOARD` 及单张返回格式，增加 `COPY_IMAGES_TO_CLIPBOARD`（`copy-images-to-clipboard`）数组入口及 preload 白名单。返回 `{ success, count, filePaths }`，失败返回 `{ success: false, error }`；渲染层只在真实成功后显示复制张数。

主进程逐个核验字符串路径、授权范围、存在、普通图片文件与可读性；全部核验通过后，一次将 `createPlistArray(filePaths)` 写入现有 `NSFilenamesPboardType`。核验失败保留原剪贴板；写入异常必须报失败，不能沿用现有单张处理里“只记录异常仍返回成功”的做法。复制只写原始文件引用，不逐张解码、重编码或写回图库。

选择逻辑共用一个小 hook，由文件夹照片页、Cos 套内照片页使用；拖框在 `VirtualGrid` 内按网格坐标与卡片布局判定，保留虚拟化和分页，禁止为了框选把全图库挂载到 DOM。现有不含图片选择的页面不启用这套处理。

数据流：

```text
照片网格 → 共用多选状态 → App 的复制命令 → preload 白名单
                                             ↓
目标应用 ⌘V ← macOS 系统剪贴板 ← 主进程路径核验与批量写入
```

最脆弱的假设：现有文件引用格式装入多个路径后，目标应用会将其识别为多张独立文件。Electron 27 官方 API 允许写入自定义格式，但这并不证明接收应用兼容。实施时先把真实系统剪贴板写入与隔离 Chromium 页面粘贴跑通，再接多选界面；若主目标只能收到一张、路径文字或链接，视为失败，停止安装并回准备说明证据，不自行增加 Swift/AppleScript/原生依赖。

官方依据：[Electron 27 clipboard 文档](https://github.com/electron/electron/blob/v27.3.11/docs/api/clipboard.md#clipboardwritebufferformat-buffer-type-experimental)。当前最新文档已经改变 API 形态，实施以项目锁定的 Electron 27 实际能力为准。

## 文件与接口边界

预计超过 8 个文件：这是两种照片入口、共享网格、菜单分发与主进程串起来的功能，不是只加一个鼠标事件。

- `src/ui/hooks/useImageMultiSelection.js`（新增）：选择集合、锚点与页面重置。
- `src/ui/components/VirtualGrid.jsx`、`src/ui/components/GridCard.jsx`、`src/ui/components/card.css`：可选框选入口、鼠标事件与选择框/高亮；默认关闭，不影响套图和角色等卡片。
- `src/ui/features/folder/FolderPage.jsx`、`src/ui/features/folder/GridCard.jsx`：图片路径和鼠标修饰键透传。
- `src/ui/features/cos/CosSetAlbumPage.jsx`：套内照片使用同一逻辑，保留原键盘导航 hook。
- `src/ui/App.jsx`：菜单 ⌘C 在查看器、输入框、当前网格间正确分发。
- `src/common/ipc-channels.js`、`src/main/preload.js`、`src/main/main.js`：新增批量入口和受控写入，不重构整个主进程。
- 对应 `tests/unit/` 测试与真实取证脚本；`package.json`、`package-lock.json`、`CHANGELOG.md`、`README.md`、`.3things/design/shell-spec-final.md`、本计划、原话与进度卡。

不涉及数据库、图库迁移、源图改写、用户设置结构、外部账号凭据、网页注入或扩展。新功能仅承诺当前 Mac；其他平台保留已有单张行为，不把 macOS 文件列表写入逻辑用于其他平台。
