状态：准备阶段产物（只读盘点，未改代码）。2026-10-25
范围：Photo Album Viewer 4.1（`main` @ `dcc4b38`）。
对照：旧版 3.13.1（`git show 66fce21^:`）、规格 §11 的 K01–K10、状态栏文案、macOS/Finder 惯例。

## 一、现状：实际生效的绑定

### 1. 全局（主窗口，App.jsx）

| 键 | 作用 | 备注 |
|---|---|---|
| ⌘[ / ⌘] | 当前标签后退 / 前进 | 输入框内不触发 |
| ⇧⌘[ / ⇧⌘] | 切上一个 / 下一个标签 | 状态栏未提示 |
| ⌘↑ | 上一级（仅文件夹页） | 其它页无动作 |
| ⌘F | 聚焦搜索（文件夹页工具栏；Cos 页找 `.cos-search`） | 其它页无输入框，无动作 |
| ⌘, | 打开设置窗口 | 仅主窗口 |
| ⌘W | 关闭当前标签（最后一个标签则回到照片来源页） | **与系统菜单冲突，见 §3** |
| 长按后退 500ms | 历史菜单 | 鼠标专用，无键盘等价 |

### 2. 文件夹页（FolderPage.jsx）

| 键 | 作用 | 备注 |
|---|---|---|
| Esc | 有搜索词→清空；查看器开着→交给查看器；否则退一级 | **输入框聚焦且搜索词为空时会误触发「退一级」** |
| Enter | 打开 `selectedKey` 对应项 | 只有列表点击后才有选中项 |
| 其它 | 无 | 方向键、Home/End、Esc 清选中都没有 |

### 3. 查看器（ImageViewer.jsx）

| 键 | 作用 | 旧版对应 |
|---|---|---|
| Esc | 先关信息面板，再关查看器 | 同（旧版还有 Backspace 关闭） |
| ← / → | 上一张 / 下一张（首尾循环） | 同（旧版还有 A/D） |
| + / = / - | 缩放 | 同 |
| i | 信息面板 | 同 |
| v | 双页 | 同 |
| f | 全屏 | 同 |
| e / r | 顺 / 逆时针旋转 | 旧版 E 右旋、Q 左旋；**旧版 R 是随机** |
| ⌘C / ⇧⌘C | 复制文件 / 复制像素 | 同，但**可能被系统菜单 Copy 抢占** |

### 4. 菜单层

`src/main/main.js` 没有 `Menu.setApplicationMenu`，用的是 Electron 默认菜单。默认菜单自带：⌘Q、⌘H、⌘M、⌘W（关闭窗口）、⌘R（重载）、⌘0/⌘+/−（网页缩放）、⌘C/⌘V/⌘X/⌘A（编辑）、⌥⌘I（开发者工具）。

## 二、问题清单

### A. 与系统菜单冲突（严重，且可能已出问题）

| # | 键 | 现状 | 后果 |
|---|---|---|---|
| A1 | ⌘W | 系统菜单是「关闭窗口」，优先级高于渲染层 | 用户按 ⌘W 很可能关掉整个窗口（而窗口全关就退出应用），不是关标签 |
| A2 | ⌘+ / ⌘− / ⌘0 | 系统菜单是网页缩放 | 查看器的图片缩放可能收不到事件；⌘0 会缩放整个界面 |
| A3 | ⌘C | 系统菜单 Copy 优先 | 查看器里 ⌘C 复制文件/像素可能实际不生效（按钮能点） |
| A4 | ⌘R | 系统菜单是重载页面 | 误按会刷新整个界面、丢当前标签状态 |
| A5 | 其它 | 默认菜单没有我们的「新建标签 / 刷新 / 设置」项 | 菜单栏里找不到这些操作，只能记快捷键 |

### B. 规格写了、实际没做

| # | 规格 | 实际 |
|---|---|---|
| B1 | K07 方向键：列表移动选中、网格移动焦点 | 两者都没有；列表行和网格卡片不可聚焦 |
| B2 | K08 回车打开选中项 | 只有「先点选列表行」后才有选中项 |
| B3 | K09 输入框内屏蔽 | 只屏蔽了 ⌘ 组合；**Esc 未屏蔽**（见 C1） |
| B4 | 状态栏矩阵 | 查看器已无状态栏；标签切换、长按后退未提示 |

### C. 不合理 / 未考虑

| # | 问题 | 说明 |
|---|---|---|
| C1 | 搜索框为空时按 Esc 会退一级 | 窗口级监听没判断事件来源是否为输入框 |
| C2 | 查看器打开时，⌘[ ⌘] ⌘W ⌘, 仍作用于背后的主窗口 | 会一边看图一边导航/关标签/开设置 |
| C3 | 最后一个标签按 ⌘W 只是回到来源页 | 与「关闭」的直觉不符；且无法用键盘关窗口 |
| C4 | ⌘F 在 Cos 页靠 DOM 兜底选择器 | Cos 总览/套内页没有搜索框，按了没反应也无提示（可接受，但应确保不误聚焦到隐藏元素） |
| C5 | 没有 ⌘T（新标签）、⌘N（新窗口）、⌘R（刷新当前文件夹） | 与 Finder/浏览器习惯不符，也没有菜单项 |
| C6 | 网格没有选中态 | 键盘导航、复制、删除都无从下手 |
| C7 | 列表/网格不可 Tab 进入 | 纯键盘用户到不了内容区 |
| C8 | 查看器没有 Delete 删除、没有 O 在 Finder 显示、没有 T 隐藏工具栏、没有 C 收藏 | 旧版都有，重做时丢了 |
| C9 | R 键语义变了 | 旧版 R=随机看下一张，新版 R=逆时针旋转；用户按旧习惯会转图 |
| C10 | 设置窗口没有快捷键约定 | ⌘W 应关设置窗口；⌘, 在设置窗口无动作 |
| C11 | ⌘A / ⌘Z / ⌘V 依赖默认菜单 | 一旦自定义菜单，必须显式保留，否则输入框编辑会退化 |

## 三、修改计划（按优先级，每批可独立验收）

### P0 · 菜单层与冲突（必须先做，约半天到一天）

1. 显式创建应用菜单，替换默认菜单：
   - **文件**：新建标签页 ⌘T、新建窗口 ⌘N、打开文件夹 ⇧⌘O、关闭标签页 ⌘W、关闭窗口 ⇧⌘W、设置… ⌘,、退出 ⌘Q。
   - **编辑**：撤销/重做/剪切/复制/粘贴/全选（保留系统角色，输入框依赖它）。
   - **显示**：网格 ⌘1、列表 ⌘2、刷新当前文件夹 ⌘R、放大 ⌘+、缩小 ⌘−、实际大小 ⌘0（后三项在主窗口里路由给查看器，没有查看器时不做网页缩放）。
   - **窗口**：最小化 ⌘M、缩放。
2. 菜单命令统一走 `webContents.send('menu-command', {command})`，preload 暴露 `onMenuCommand`，主窗口与设置窗口各自处理；不再让任何菜单项直接 `Close Window` 或 `Reload`。
3. 验收：真机逐项按一遍（菜单加速器和渲染层是两套路径，必须真机验），并补一条「⌘W 只关标签、不关窗口」的回归测试。

### P1 · 查看器键位与作用域（约半天）

1. 恢复旧版键位：A/D 前后退、Backspace 关闭、Delete 移到废纸篓（二次确认）、O 在 Finder 显示、T 隐藏/显示底栏、C 收藏；E 右旋、Q 左旋，**R 恢复为随机**（与旧版一致）。
2. 查看器打开时吞掉 ⌘[ ⌘] ⌘W ⌘, ⌘T ⌘N（不作用于背后窗口）；Esc 仍按现有三级。
3. ⌘C 走菜单路由：菜单 Copy 在有查看器时执行「复制文件」，否则执行系统复制。
4. 验收：查看器内逐键真机验证 + 单测覆盖作用域（背后标签不变化）。

### P2 · 列表与网格键盘导航（约一天）

1. 列表：↑↓ 移动选中（到顶/到底不循环）、Home/End 跳首尾、Enter/双击打开、Esc 清选中。
2. 网格：引入选中态（当前卡片有焦点环），方向键按行/列移动，Enter 打开，Esc 清选中；Tab 能进入内容区。
3. 统一「选中」与「打开」的视觉：选中只描边，不打开。
4. 验收：单测 + 真机走一遍三种尺寸，确认焦点环在深色背景上可见。

### P3 · 状态栏与帮助（约半天）

1. 每页状态栏改成由同一张「键位表」渲染，杜绝页面各处手写字符串导致的不一致。
2. 查看器恢复一条极简提示（例如 hover 底部时显示，或按 `?`）。
3. 新增「键盘快捷键」帮助：设置窗口加一页，或按 ⌘/ 弹出面板，按作用域分组。
4. 验收：状态栏文案与帮助面板、实际绑定三者一致（可加脚本比对）。

## 四、需要你拍板的三件事

1. **⌘W 语义**：建议 ⌘W 关标签、⇧⌘W 关窗口、最后一个标签时关窗口（浏览器习惯）。若你想要 Finder 习惯（⌘W 直接关窗口），我按那个做。
2. **单键快捷键只放在查看器里，还是列表页也恢复？** 建议只在查看器（看图时键盘独占，误触代价低）；列表页单键（C 收藏、R 随机）容易误触，不做。
3. **⌘R 的语义**：刷新当前文件夹（重新扫描）；若你在 Cos 页按，是否也刷新 Cos 索引？建议只刷新当前视图的数据，不重建索引。

## 五、已知需要真机验证的疑点

- ⌘W / ⌘+ / ⌘C 到底被系统菜单还是渲染层接住：需要在装好的应用里真实按键（CDP 合成事件绕不过菜单加速器）。
- 设置窗口的焦点与菜单路由是否正常。
