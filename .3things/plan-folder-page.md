# 计划 · 「文件夹」页换成 A（接着看 + 最近有变化）

> 阶段：计划。本文件只写步骤与验收，不动代码。
> 依据：[用户原话 10-27 09:35](../acceptance/2026-10-26-user-voice.md)（选了 A，见 10-27 10:33 条目）；样张 [folder-page-round1.html](design/folder-page-round1.html) 屏 2；记录 [folder-page-round1-notes.md](design/folder-page-round1-notes.md)。
> 版本目标：**4.6.0**（minor，新功能）。分支：`codex/folder-page-overview`。

## 一、这轮做成什么样

侧栏点「文件夹」进来的这页，从「另一份来源清单」变成两个只属于它的区块：

1. **接着看**：最近打开过的两个文件夹，各带封面、名称、来源、张数、相对时间；点一下回到那一层。
2. **最近有变化**：跨来源、按修改时间排的列表（名称 / 来源 / 张数 / 时间 / 缩略图），点一行进入该文件夹。

侧栏、Cos 四页、我的收藏、查看器都不动。

## 二、我替你定的几件事（不同意就说，改了再开工）

1. **页名**：页头从「照片来源」改成「文件夹」，与侧栏、标签页一致。
2. **与 Cos 总览的分工**：Cos 总览的「最近添加」这轮不动。它的粒度是套图，这页的粒度是文件夹、覆盖全部 9 个位置（含 兴趣 / Downloads 这些没进 Cos 索引的）。两处会看到同几套新图，先跑一轮看你觉得烦不烦；真烦，下一轮把 Cos 总览那段收掉。
3. **窗口**：只列最近 7 天、最多 10 条；「接着看」最多 2 张。
4. **嵌套来源**：子目录如果本身就是另一个已注册来源（兴趣、300/400/600、twitter_media_harvest、P图用模特），在「最近有变化」里跳过，避免同一件事出现两次。
5. **点点看的方式**：点整行 = 进入该文件夹（与文件夹网格单击打开一致），不做展开。

## 三、步骤

### S1 · 记忆层（看不到变化）

做什么：新增 `src/ui/data/recentLocations.js`——localStorage 键 `pav.recent-locations.v1`，每个来源只留最近一条 `{sourceId, relativePath, at}`，总量上限 20 条；提供 `recordLocation` / `listRecentLocations` / `forgetLocation`，JSON 损坏或存储不可用时静默返回空。`App.jsx` 在 location 切到 `kind: 'folder'` 时记录（走 effect，让返回/前进/恢复会话也算）。

用户看到什么：无。

怎么验收：`tests/unit/recentLocations.test.js` 覆盖写入覆盖、按时间倒序、坏数据容错、条数上限；`npm test` 全绿。

### S2 · 新骨架 + 最近有变化（第一次看得见）

做什么：
- 重写 `RootsPage.jsx`：页头（「文件夹」+「9 个位置 · 今天 N 个有改动」+ 打开文件夹）、`接着看` 区块占位、「最近有变化」列表。删掉 `.roots-grid` / `.root-card` 网格和对应 CSS。
- 数据：对每个来源并发 `getDirectoryLevel(source, '')`（沿用现有调用与主进程快照缓存），用 `allSettled` 逐条 setState，列表渐进填充。派生规则：children 里 `mtimeMs` 在 7 天内、`facts.directMediaCount > 0`、且不是已注册来源的子目录，按 mtime 降序取前 10。
- 每行点击 → `navigate({kind:'folder', sourceId, relativePath})`；缩略图用该文件夹 `approximate.coverSamples[0]` 走 `Thumb`。
- 读取中显示 6 行骨架；读不到的来源不出现在列表里，页脚一行「N 个位置读不到 · 重试」（旧的每张卡一个重试按钮取消）。
- 页面不再列出来源，进某个来源的第一层改由侧栏点（侧栏本来就有）；这页只负责「接着看」和「最近有变化」。
- 测试改造：
  - `tests/unit/uiMatrix.test.jsx` 里「照片来源」标题断言改「文件夹」；`RootsPage` 的读失败用例改成断言页脚提示与重试。
  - `tests/unit/uiEscLayers.test.jsx` 的 `.root-card` 锚点失效，改成用页面容器判定「在文件夹页」，进来源根改点侧栏来源项；Esc 分层行为本身不变。

用户看到什么：打开「文件夹」页，两秒内看到标题和「最近有变化」列表；最后一行是真实的最近改动（今天应能看到 兴趣/003-banana pro 3,088 张、300-Cos套图库 10-26 那三套）。

怎么验收：`npm test`；真机打开页面截图，与样张屏 2 下半部分并排比对；点三行分别进到对应文件夹再 Esc 回来。

### S3 · 接着看（重启后回到上次）

做什么：两条记录的封面用该文件夹快照的 4 个 `coverSamples` 拼 2×2（复用 `src/ui/features/folder/FolderCover.jsx` 的拼贴写法与 `.collage` 样式），卡面标题两行截断、次级行「来源 · N 张 · 相对时间（今天 / 昨天 / 10-25）」，右上「继续」。记录对应的文件夹已不存在时清掉该条记录并隐藏卡片。无记录时该区块显示一行「还没有打开过文件夹」+「打开文件夹」按钮。

用户看到什么：进过 300 里的某套、回 600 里的某页之后，再点「文件夹」，页面上方出现这两张卡；点一张直接回到那层，面包屑与网格对得上。重启应用后卡片仍在。

怎么验收：真机按上面路径走一遍并截图；`npm test` 增加 RootsPage 的接着看用例（有记录 / 无记录 / 路径失效三种）。

### S4 · 收边

做什么：
- 空库（0 个来源）保留现有空状态；单来源时布局不塌。
- 窄窗口（900 / 720 宽）：接着看由两张并排改一张一行；页头计数与按钮不换行。
- 性能：首屏只依赖「接着看」（本地数据，立即渲染），「最近有变化」由扫描结果渐进填充，扫描不阻塞页面；不新增扫描次数（与今天的 RootsPage 相同）。
- 键盘与 Esc：页面本身是顶层，Esc / ⌘↑ 无动作（与 4.5.3 一致）；列表行不进入选中态。
- 补齐单测：聚合规则（7 天窗口、0 张过滤、嵌套来源跳过、排序、上限 10）。

用户看到什么：窗口拉窄、没有来源、有来源读不到时，页面都不崩、不留白。

怎么验收：`npm test` 与 `npm run check:unwired`；真机 1280×820、960×700、720×480 三档截图。

## 四、真机验收清单（S5 全跑）

1. 冷启动 → 打开「文件夹」：标题「文件夹」，接着看空态、最近有变化在两秒内出现内容。
2. 进 300-Cos套图库 的 Machi 某套 → 返回「文件夹」：接着看出现这张卡，点它回到该套。
3. 再进 600-Cos Weibo 某页 → 回「文件夹」：两张卡都在，顺序按打开时间倒序。
4. 重启应用 → 接着看两张卡仍在，点开位置正确。
5. 隔离 profile 里加一个指向不存在路径的来源 → 该来源不出现、页脚提示、不影响其余列表；把路径恢复后点重试能出现。
6. 300-Cos套图库 清掉主进程缓存后首次进页面：先看到骨架，列表随后补齐，期间可点接着看。
7. 窗口 960 宽、720 宽：布局不破，无横向滚动。
8. 从页面点一行「最近有变化」→ 进入该文件夹 → Esc 回到「文件夹」页。

## 五、风险与回滚

- **扫描耗时**：300-Cos套图库 首层 9,585 个目录要逐个子目录 readdir。今天这页本来就这么做，这轮不增加次数；如果真机首屏超过 2 秒还没出任何内容，属于 S4 未达标，处理方式是把列表改成「先出 2 条、随到随补」的更高频 setState，不新增主进程能力。
- **缓存陈旧**：主进程快照按根目录 mtime 判断缓存，套图文件夹内部新增图片不会让根 mtime 变。表现是：在已有套图里新增照片，这页可能落后一次。接受，不改这轮。
- **回滚**：全程在 `codex/folder-page-overview` 分支；出问题 `git revert` 或退回 `a7b6a5a`。安装包替换前保留旧 `.app` 副本。

## 六、不做

侧栏改造、Cos 总览的「最近添加」、磁盘剩余空间、递归张数 / 目录总大小、全局搜索、多选与批量操作、来源改名（这轮只管展示与管理入口不做）。
