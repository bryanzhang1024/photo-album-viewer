# 查看器「左键单击逐级放大」恢复计划（目标 4.7.0）

状态：准备+计划阶段产物（只读核对 + 分步计划，未改产品代码）。2026-10-29
基线：`main` @ `684c224`（4.6.0，安装版 4.6.0）。

## 一、需求原话与还原

| 时间 | 原话 | 转成要求 |
|---|---|---|
| 2026-10-29 00:1x | 「之前有点左键放大的功能，点一下放大一些，多点几下能放更大，4.0重做之后没做进去，想要这个功能」 | 查看器里左键单击 = 放大一档，连续单击继续变大；4.0 重写时漏掉了，恢复即可 |

## 二、旧版行为（代码证据）

旧界面查看器源码 `src/renderer/components/ImageViewer.js` 在 4.0.0 切换默认界面时删除（提交 `7a81036`）。删除前版本里的实现：

- 提交 `d8ada10`（2025-09-30）「feat(viewer): 左键单击放大并修复拖动冲突」，说明里写明「将图片查看器中的左键单击行为统一为放大图片，取代了之前根据点击区域（左/右半边）切换图片的功能」。
- 判定方式：鼠标按下到松开 **小于 200 ms** 且位移 **小于 5 px** 视为单击，执行放大 `×1.2`；否则按拖动处理。
- 连续单击即连续乘 1.2：`120% → 144% → 173%`；旧版缩放下限 10%、上限 500%。
- 拖动只改变图片位置，不改变缩放；右键关闭；滚轮翻页、⌘/Ctrl+滚轮缩放。

## 三、4.6.0 现状与差异

- 查看器**左键按下即拖动平移**（任何缩放级别），单击（不拖）没有任何动作；放大只能靠 ＋ 按钮 / `+` 键 / ⌘滚轮 / 设置里的缩放步长。
- 缩放下限 20%、上限 **800%**，默认步长 20%（`settings.zoomStep`），＋ 按钮即 `×1.2`。
- 查看器舞台（`.viewer-stage`）内部还有左右翻页箭头按钮，恢复单击放大时必须排除，否则点箭头会「翻页 + 放大」同时发生。

## 四、恢复口径（默认，等你确认）

| 项 | 旧版 3.11 | 4.7.0 恢复方案 |
|---|---|---|
| 触发 | 左键短按 + 位移 <5px | 相同：<200 ms 且 <5 px |
| 步长 | 固定 ×1.2 | 跟设置「缩放步长」，默认 0.2 即 ×1.2（与 ＋ 按钮同一档） |
| 上限 | 500% | 沿用 4.x 的 **800%**（与 ＋ 按钮一致；要改回 500% 请说） |
| 拖动 | 放大后才可拖 | 保持现状：任何时候都能拖；位移 ≥5px 只拖不放大 |
| 翻页箭头 | 无此冲突 | 点在按钮上不放大，只翻页 |
| 其它 | — | 滚轮翻页、⌘滚轮缩放、右键关闭、双页、旋转、Esc 全部不变 |

不做：不改成「以点击位置为锚点」的缩放（旧版是居中缩放）；不改网格页单击打开；不加双击特判（双击=两次单击=两档，与旧版一致）。

## 六、真机验收点（S4 用 CDP 断言，截图存 `acceptance/evidence/viewer-click-zoom/`）

1. 单击舞台一次 → 缩放显示 `120%`；
2. 连点三次 → `173%`；
3. 拖 20 px 再松手 → 缩放仍 `100%`，图片位移改变；
4. 点右箭头 → 换到下一张，缩放仍 `100%`；
5. 点到 800% 后继续单击 → 仍是 `800%`；
6. ⌘滚轮缩放、滚轮翻页、右键关闭、Esc 关闭行为与 4.6.0 一致。
